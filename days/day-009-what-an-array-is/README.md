## What you can do by tonight

- **DSA** — You can explain why arr[500000] is as fast as arr[0], using one picture.
- **System design** — You can order register, cache, RAM, SSD, disk and network by speed, and say how far apart they are.
- **Languages** — You can make a function fail in each language and make the caller handle it, and say which style each language prefers.

## The questions today answers

- *Why is array indexing O(1)?*
- *How much slower is a disk read than a memory read?*
- *Should this function throw, or return an error?*
