## What you can do by tonight

- **DSA** — You can count how many times a loop body runs, for any input size, without running the code.
- **System design** — You can draw the client-server picture and say exactly which machine does what.
- **C++** — You can choose int or long long correctly, and spot the multiplication that will overflow before you run it.

## The questions today answers

- *How many times does the inner loop execute if the array has n elements?*
- *What is the difference between a client and a server? Where does your code live?*
- *What is the range of an int, and what happens when you go past it?*
