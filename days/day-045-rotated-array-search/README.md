## What you can do by tonight

- **DSA** — You can binary search data that is sorted, but not from the start.
- **System design** — You can say why public fields are a design bug, with a concrete failure.
- **Languages** — You can fetch 200 URLs with a bounded pool, timeouts, and retries, in all three.

## The questions today answers

- *Search a rotated sorted array in O(log n).*
- *Why make a field private if you are going to add a getter anyway?*
- *How would you download a thousand files as fast as possible without overloading the server?*
