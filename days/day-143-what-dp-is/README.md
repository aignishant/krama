## What you can do by tonight

- **DSA** — You can define DP as recursion plus memory, and recognise the overlapping subproblems.
- **System design** — You can trade a little accuracy for a lot of memory, and say when that is safe.
- **C++ for contests** — You can allocate a DP table of any shape, memoise with a sentinel, and name the five bugs that still cost you contests.
- **Languages** — You can retry failed jobs safely and quarantine the ones that will never succeed.

## The questions today answers

- *Why is this exponential, and how do you fix it?*
- *How do you check whether a URL has been crawled, using little memory?*
- *How would you write a 2D DP table in C++, and what does it cost in memory?*
- *What is a poison message?*
