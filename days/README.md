# Daily sessions

## Navigation — where to start

1. Open [Day 1](day-001-count-target-values/LESSON.md), or find your day in the
   [master plan](../docs/00_MASTER_PLAN.md).
2. Choose the subject README and follow its numbered route from explanation to practice.
3. To recall previously studied topics without practice, open [DSA](../docs/DSA_RECALL.md),
   [Python](../docs/LANG_RECALL.md), or [system design](../docs/SD_RECALL.md).

Open a numbered folder, then dsa_<topic>/, sd_<topic>/ or lang_<topic>/. All 168 days have all three.
The full map is in [the master plan](../docs/00_MASTER_PLAN.md).
Use `python course.py start 1 --track dsa` from the root to find the first assignment.
