## What you can do by tonight

- **DSA** — You know the real cost of append, pop, insert and a slice, so you stop writing accidental O(n^2).
- **System design** — You can write out a real HTTP request and response by hand and label every part.
- **C++ for contests** — You can use vector for every array problem in the course, and pass one to a function without copying four megabytes by accident.
- **Languages** — You can write a function with several inputs and outputs in each language and explain where each argument lives.

## The questions today answers

- *What is the complexity of inserting at the front of a Python list?*
- *Describe an HTTP request. What is in the headers, and what is in the body?*
- *What is the difference between passing by value, by reference, and by pointer?*
- *How does each language return more than one value?*
