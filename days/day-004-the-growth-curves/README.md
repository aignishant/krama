- **DSA** — You can rank O(1), O(log n), O(n), O(n log n), O(n^2), O(2^n) and know what input size each survives.
- **System design** — You can say why a video call uses one and a bank transfer uses the other.
- **Languages** — You can write every loop shape in each language and pick the one that reads cleanest for a given job.

## The questions today answers

- *n is 100000. Will an O(n^2) solution pass?*
- *TCP or UDP for a live video call, and why?*
- *Write a loop that stops early. Now write it without break.*
