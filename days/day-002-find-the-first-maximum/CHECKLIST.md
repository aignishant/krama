Reading a lesson does not complete an objective. Use these checks for your own work.

## Read and explain

- [ ] dsa: read [the lesson](dsa_find-the-first-maximum/CONCEPTS.md), trace the example, and pass its readiness check. Explain initialization from a real element, strict tie handling, and the empty-input result.
- [ ] sd: read [the lesson](sd_quality-requirements/CONCEPTS.md), trace the example, and pass its readiness check. Name the population, boundary, window, and assumed target for each quality requirement.
- [ ] lang: read [the lesson](lang_shallow-and-deep-copies/CONCEPTS.md), trace the example, and pass its readiness check. Assert outer identity, nested sharing, and isolation after mutation.
- [ ] Online DSA route: explain [dominance verification](dsa_find-the-first-maximum/DOMINANCE.md); optional for local practice.

## Practice and verify

- [ ] Choose one DSA route; justify correctness and costs with distinguishing tests.
- [ ] Observe and explain a plausible failure, then verify its repair.
- [ ] Write the design artifact with assumptions, an alternative, and a failure walkthrough.
- [ ] Predict the Python experiment, run it, and add meaningful regression assertions.
- [ ] Save actual evidence and help used in the appropriate subject files.

## Record independently

- [ ] DSA core and its acceptance criteria complete.
- [ ] SD deliverable and critique complete.
- [ ] Python experiment and explanation complete.
- [ ] Append separate track results; append whole-day progress only when all three pass.
