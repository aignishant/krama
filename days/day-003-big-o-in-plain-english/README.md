## What you can do by tonight

- **DSA** — You can say O(n), O(n log n) or O(n^2) about your own code and defend the answer.
- **System design** — You can explain how a name becomes a machine, and what a port is for.
- **C++ for contests** — You can read any judge's input format fast enough, and say what every line of your template actually does.
- **Languages** — You can build, slice, search and format text in each language, and say why a Hindi word has a different length in each.

## The questions today answers

- *What is the time complexity of your solution?*
- *How does the browser find the server for google.com?*
- *Your algorithm is optimal and it still times out. What do you check?*
- *Why does the length of a string not always equal the number of characters?*
